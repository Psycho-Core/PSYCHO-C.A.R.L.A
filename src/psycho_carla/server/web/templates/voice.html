C.A.R.L.A. VOICE AUDITION

CPU-only synthesis — no cloud, no GPU loading
Read this first. Neither Piper nor Kokoro ships an Irish (en_IE) voice — I verified this against the full voice manifests (Piper: 182 voices, zero en_IE; Kokoro: American/British/Japanese/Mandarin/Spanish/French/Hindi/Italian only). So the honest answer to “does it sound like C.A.R.L.A.?” is: the closest CPU-available options are British English, not Irish. The persona text, cadence and dry wit are what make it C.A.R.L.A. — the accent is a separate axis. Listen, pick the closest, and I can wire it in as the default.
Lines are the actual strings emitted by core/persona.py — what you hear is what the system says.
Piper = ONNX, ~22 kHz, very fast, slightly clipped.  Kokoro = 82M params, 24 kHz, smoother and more natural, slower on CPU.
To swap the default voice: set [voice].tts_engine and [voice].tts_voice in psycho_carla.toml, then run carla doctor to confirm the backend resolved.
